📊 SelfAgriBook — Hub compta

Journal des écritures comptables alimenté en temps réel par tous les modules MySelf (factures, achats, banque, immos). Zéro double saisie, dédup automatique par (source_module, source_id).

⚠ Démo publique partagée — la base SQLite est commune à tous les visiteurs. Si quelqu'un d'autre teste en même temps, vos écritures se mélangent et un reset purge pour tout le monde. En installation réelle MySelf, la DB est locale (~/.selffarm/compta.db) et isolée par utilisateur·ice.

Facture Factur-X du journal (consolide les ventes 411/701 du journal) : ⚡ la source de vérité est le hub compta. Lignes = écritures réelles, pas aléatoires. Document légal PDF/A-3 + XML EN16931.
Les 3 flux alimentent le même hub — chaque module déclare sa source (self_compta_manuel, self_achats, self_invoice), la dédup par source_module + source_id garantit l'idempotence.

Architecture hub

Une seule table ecritures_comptables. Chaque module MySelf y pousse ses auto-écritures :

  • self_invoice → 411/701
  • self_achats → 6011/401 (V2)
  • self_banking → 512/411 (V2)
  • self_immos → 2154/404 (V3)
  • self_aides → 512/74 (V3)

Stockage SQLite local ~/.selffarm/compta.db. Aucun cloud, aucun SaaS.
