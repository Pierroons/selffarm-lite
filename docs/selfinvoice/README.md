# SelfInvoice — documentation d'origine

Ces quatre documents viennent du dépôt `my-self`, où SelfInvoice occupait un
dossier au rang des piliers de l'écosystème. Il n'en était pas un : le dossier
ne contenait aucune ligne de code, et l'implémentation vit ici, dans
`webapp/templates/invoice` et `webapp/static/invoice-demo`.

Ils ont donc rejoint le dépôt qui porte le code, le 18 août 2026.

| fichier | registre |
|---|---|
| `whitepaper.md` / `.docx` | descriptif public, en anglais — problème, architecture, matrice de mentions légales, modèle de données, moteur de rapprochement |
| `presentation-fr.md` / `presentation-en.md` | vitrine bilingue du module (anciens `README.fr.md` / `README.md`) |

Ils **ne remplacent pas** `../architecture-selfinvoice-v0.2.md`, qui reste la
spec d'implémentation : stack, découpage du monorepo, API Viva, plan de
travail. Trois registres distincts — le whitepaper décrit ce que fait
SelfInvoice, la présentation à qui il s'adresse, l'architecture comment il est
construit. Le whitepaper porte la version `alpha 0.0.1` (avril 2026) ; en cas
de contradiction sur un point technique, c'est l'architecture v0.2 qui fait
foi, étant postérieure.
